# Multidisciplinary Review

## Objective

Improve consequential reasoning by selecting the smallest useful set of
independent professional lenses, preserving disagreements among them, and
turning the synthesis into a decision, test, or next action.

This Skill operationalizes requested expert perspectives. It does not imitate,
quote, or claim to represent any named person, university, consultancy, or
company.

## Activation

Use this Skill when:

- the user explicitly requests a top-tier, multidisciplinary, first-principles,
  philosophical, strategic, executive, or cross-functional review;
- a consequential decision materially spans several of research, philosophy,
  business, organization, systems, AI/ML, data, or cloud engineering; or
- competing professional perspectives would expose assumptions or tradeoffs
  that a single-domain review would likely miss.

Do not activate it merely because an ordinary task could be viewed from many
angles. Use a narrower Skill or direct reasoning when that is sufficient.

## Core Rules

- The user's explicit goals and constraints take precedence over this Skill.
- Translate named exemplars into methods and evaluation criteria. Do not use
  prestige, institutional affiliation, or a famous name as evidence.
- Select only the lenses that can materially change the conclusion.
- Distinguish observed facts, sourced evidence, derivations, assumptions,
  value judgments, hypotheses, and unresolved uncertainty.
- Do not force consensus. Preserve genuine conflicts and state what decision or
  evidence would resolve them.
- Match depth to stakes. A lightweight decision needs a lightweight review.
- Do not let the review replace execution when the next useful step is a test,
  calculation, prototype, or user decision.

If the task contains substantive academic or scientific claims and a research

reproducibility. This Skill adds cross-domain diagnosis and synthesis; it does
not weaken research evidence requirements.

## Review Procedure

1. State the decision, claim, or question; the decision owner; relevant time
   horizon; and material constraints.
2. Select the minimum useful lenses and explain the selection briefly when it
   is not obvious.
3. For each lens, identify:
   - the central diagnosis;
   - assumptions and missing information;
   - the strongest objection or failure mode;
   - a leverage point, discriminating test, or concrete action;
   - confidence and residual uncertainty.
4. Synthesize convergence, conflicts, and tradeoffs without averaging away
   incompatible conclusions.
5. End with a proportionate recommendation, falsification or reversal
   conditions, the next action, and any decision reserved for a human.

## Stopping Condition

Stop when the selected lenses no longer produce material new information, the
important conflicts and uncertainties are explicit, and the user has a clear
decision, experiment, or next action. Do not add perspectives only to make the
review appear more comprehensive.
